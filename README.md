# 🌍 Site sobre a Primeira Guerra Mundial  

Este projeto é um **site educacional** desenvolvido para o componente curricular de **História**, abordando a **Primeira Guerra Mundial**.  
O site combina **HTML, CSS e JavaScript** para apresentar conteúdo histórico de forma interativa e didática.  

---

## 📌 Conteúdo do site
- ✅ Linha do tempo dos principais eventos da Primeira Guerra Mundial  
- ✅ Perfis de países envolvidos  
- ✅ Explicação sobre causas, batalhas e consequências  
- ✅ Galeria de imagens e mapas históricos  
- ✅ Quizzes e atividades interativas para aprendizado  

---

## 🛠 Tecnologias
- **Front-end:** HTML, CSS, JavaScript  
- **Extras:** Uso de animações e interatividade com JS  
- **IDE:** VS Code
